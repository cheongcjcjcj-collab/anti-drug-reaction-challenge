# 攤位互動遊戲｜禁毒反應挑戰

一個為青少年禁毒教育攤位而設的互動網站。參加者可完成「毒品偵探」及「守住支援」兩個挑戰，從遊戲中認識常見毒品風險、香港相關法律後果，以及面對誘惑或壓力時可採取的健康選擇。

## 網站

- 線上版本：https://anti-drug-reaction-challenge.cqrgjcp7wz.chatgpt.site
- 適合桌面、平板及手機使用
- 可切換全螢幕，方便活動攤位展示

## 主要功能

- **毒品偵探**：隨機辨認毒品圖片、健康風險、法律後果及拒絕情境。
- **守住支援**：30 秒反應遊戲，拍走錯誤觀念，同時保留健康活動與支援選擇。
- **完成進度**：記錄參加者完成兩個挑戰的進度。
- **今日榜**：以瀏覽器 `localStorage` 儲存最多 20 項成績；資料只會保留在目前裝置。
- **教育提示**：答錯時顯示相關提醒；完成後整理重點。
- **QR Code**：網站頁尾提供 Instagram、中心網站及中心 QR Code。

## 技術

- React 19
- Next.js 16
- TypeScript
- Vinext / Vite
- Cloudflare Workers 相容建置

## 本機執行

需要 Node.js 22.13 或以上版本。

```bash
npm ci
npm run dev
```

網站預設由 Vite 開發伺服器啟動；請按終端顯示的本機網址開啟。

## 建置與測試

```bash
npm run build
npm test
```

`npm run build` 會建立並驗證可部署的網站檔案；`npm test` 會額外檢查渲染結果。

## 主要檔案

```text
app/
  page.tsx          # 遊戲內容、題目與互動邏輯
  globals.css       # 網站版面、動畫與響應式設計
public/
  drugs/            # 教育用途毒品圖片
  *-qr.png          # 活動及中心 QR Code
tests/              # 渲染測試
worker/             # Cloudflare Worker 入口
```

## 資料與私隱

網站沒有將排行榜傳送到外部資料庫。參加者名稱及分數只儲存在使用該網站的瀏覽器內；如使用共用裝置，活動完結後可清除瀏覽器網站資料。

## 教育用途聲明

網站內相片只供教育用途。受管制物質的外觀及成分可能改變，不應單靠外觀判斷。網站提供的是一般禁毒教育資訊，並不取代法律、醫療或緊急支援服務。

## 圖片及內容

網站圖片、QR Code、文字及互動內容均收錄在本 repository，供此禁毒教育網站運作及維護之用。使用或再發布前，請先確認相關內容及圖片的授權與機構要求。
